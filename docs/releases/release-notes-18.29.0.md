# 小驴打卡 v18.29.0

「集市版本平滑升级、顶栏门面净化与连续打卡蜂蜜暖金色彩调优」小版本发布：针对社区集市（Bazaar）自动索引对版本号单调递增的要求，正式递增语义化版本至 v18.29.0；净化主界面顶部导航栏，彻底移除了误放置在常规顶栏的独立弹窗专用版本药丸徽标，恢复为呼吸感极佳的简洁品牌门面；深度调优 Today 连续打卡卡片视觉色彩，彻底排查并清除了覆盖浅白渐变与右下角白色虚晕冲突，全量对齐高对比度蜂蜜金暖调（Amber-800 浓郁焦糖文字 + Amber-100 温润底色），对比度超过 6.8:1，字迹清晰通透。主存储保持向前兼容，最低思源版本仍为 3.8.4。

## 核心更新

### 1. 社区集市：索引版本递增规范对齐（R-BUMP-18.29.0）
- **版本号递增以满足集市抓取检验**：针对覆盖已上架版本时集市机器人校验拦截的规则，将版本号从 18.28.0 规范递增至 18.29.0，并全面补齐 `plugin.json` 中的 `zh_CN` 与 `zh-CN` 双键兼容声明。

### 2. 界面与门面：主窗口顶栏版本药丸徽标移除（T-1924）
- **顶栏呼吸感恢复**：彻底移除了误放在主界面常规顶栏品牌区域中的紫色版本号药丸徽标，消除挤压“今日”标签页的不适感，版本号归位至“设置 ➔ 关于”专属信息行。

### 3. 视觉与美学：连续打卡卡片蜂蜜暖金与文字对比度调优（T-1925）
- **根治浅白渐变冲突与发灰发虚**：清除了 `polish.scss` 中残留的泛白渐变覆盖和右下角发虚的白色光斑；
- **WCAG AAA 级高对比度温润暖调**：将标题“当前最佳连续”、天数“2”、“天”与项目名统一收敛为高对比度的浓郁焦糖琥珀色（`#92400E`），配合轻快温暖的琥珀蜂蜜黄底色（`#FEF3C7`），与左侧完成进度卡片完美和谐呼应。
