# 小驴打卡 v18.46.0

本版本为聚焦【事项 2.0 / 2.1】生态重塑、打卡化紧凑设计、7大语义分类与小驴全家桶深度联动的里程碑版本：
- **事项卡片打卡化紧凑重构**：学习今日打卡卡片紧凑设计，单卡高度大幅压缩 60% 至 126px，正面呈现可点击标题 + 醒目倒数胶囊 + 一行核心日期周期元数据，点击标题或编辑按钮 100% 实时回填右侧编辑表单，次要信息默认收进「更多详情」折叠区，桌面端双列自适应网格消除翻页；
- **全高顺畅滚动彻底根治**：定位并清除了事项列表面板历史残留的固定高度与 `overflow: hidden` 剪裁死锁，事项页全面对齐「今日」与「回顾」页的标准原生滚动行为，支持鼠标滚轮与拖拽顺滑滚至底部；
- **7 大语义分类与顶部胶囊筛选**：建立 🎂 生日、💍 纪念日、💳 定期支出、🔄 会员续费、🏥 健康与车辆、🏮 节日、📌 计划事项 7 大分类，自动智能推断存量事项，顶部提供一键分类胶囊快速筛选与计数；
- **Task Horizon v3.3.6 与思源《📅 小驴事项簿》同源任务块双向对账**：自动在思源笔记中维护底层原生复选框块（`- [ ]`，`type='i' AND subtype='t'`），原子写入 Task Horizon 所需全部 `custom-*` 块属性，无需重复造轮子，小驴事项在 Task Horizon 大月历、看板、时间轴、四象限同源原生可见；支持监听 `tm:task-completed` 与思源块 `[x]` 自动对账回流；
- **小驴全生态（人脉/管家/雷切/快门/常用）深度双向闭环**：
  - **小驴人脉（siyuan-contacts）**：一键从人脉通讯录同步带生日的联系人至事项簿，卡片直通人脉档案文档，勾销生日事项自动回流调用人脉互动足迹；
  - **小驴管家（siyuan-home）**：支出/续费/健康事项卡片直达管家到期提醒，勾销事项自动向全域广播生态事件；
  - **小驴雷切（siyuan-speed-switch）**：扩充富语义分类、时刻与优先级，全面适配雷切全新 Bento 3.0 近期事项便当盒卡片；
  - **小驴快门（siyuan-quickgate）**：暴露 `parseQuickOccasion` 与 `addOccasionQuick` 支持全局一句话秒级录入事项并同步镜像至思源块。

## 核心更新

### 1. 事项卡片紧凑打卡化重塑与表单回填修复
- **学习打卡卡片紧凑质感**：事项卡片由原本 312px 冗长单列压缩为 126px 紧凑双列网格，正面只展示可点击标题按钮、倒数胶囊、优先级、核心日期时间，次要详情（改期、错过补偿、周期条、引文、备注）收纳至折叠区；
- **编辑回填彻底修复**：消除表单草稿与正在编辑事项 ID 之间的串台竞争，点击标题或编辑按钮 100% 完整回填表单全部字段；
- **顶部极简副标**：精简定位说明为弱对比单行副标，桌面端闭合状态抽屉横条静默隐藏。

### 2. 根治列表滚动阻断与全高自适应
- **消除截断死锁**：彻底移除 `occasion-list-panel` 历史残留的 `max-height: calc(100vh - 190px)` 与 `overflow: hidden; contain: layout paint`；
- **统一整页顺畅滚动**：事项页与今日页、回顾页完全一致，由最外层 `.lc-checkin` 承载顺滑滚动，右侧编辑面板自然吸顶伴随，所有卡片及底部的「更多与帮助」无死角直达。

### 3. 7 大语义分类体系与顶部胶囊过滤
- **分类语义化**：细分生日、纪念日、定期支出、会员续费、健康车辆、节日、日程计划 7 大分类，存量事项按关键词智能推断；
- **顶部快速筛选胶囊**：顶栏提供分类芯片栏，点击即时过滤列表并呈现动态计数；
- **块属性沉淀**：自动将分类持久化为 `custom-lv-occasion-category` 块属性，供外部插件结构化检索。

### 4. Task Horizon v3.3.6 原生任务块同源双向对账
- **原生复选框列表项维护**：零配置维护《📅 小驴事项簿》，递归解析并直接维护思源原生任务块 `type='i' AND subtype='t'`；
- **标准属性原子写入**：写入 `custom-completion-time`、`custom-start-date`、`custom-time`、`custom-priority`、`custom-status`、`custom-milestone-event`、`custom-remark`、`custom-task-horizon-attr-host-owner`；
- **Task Horizon 大月历与看板直通**：顶栏提供日历排程与看板按钮，直接唤起 Task Horizon 重型视图；
- **双向勾销与周期推进**：跨插件勾销任务自动回流小驴打卡，周期事项自动推进下期日期并复位 `[ ]`。

### 5. 小驴生态（人脉/管家/雷切/快门）深度联动
- **小驴人脉双向闭环**：事项页「更多」面板支持一键同步人脉生日至事项簿；卡片直达人脉档案文档；勾销生日自动调用 `LvContacts.recordInteraction` 沉淀交往足迹；
- **小驴管家资产维保**：支出/续费/健康事项直达管家到期提醒，勾销广播标准生态信封；
- **小驴雷切 Bento 3.0**：扩充富语义分类与倒数，适配雷切全新 Bento 3.0 近期事项便当盒卡片；
- **小驴快门一句话秒级创建**：公开 `parseQuickOccasion` 与 `addOccasionQuick` 接口。

### 6. 全生态穿透搜索、AI 教练与自动化规则联动
- **全生态穿透搜索（Omnisearch）**：接入全局搜索总线，一键穿透检索习惯、打卡流水随笔与事项簿，支持思源块直达与页面秒级定位；
- **IFTTT 自动化规则引擎（Automation）**：管家临期到期事项自动在今日打卡生成高优待办项，消除存储锁自死锁并保障秒级实时上屏；
- **AI 习惯韧性教练（Habit Coach）**：回顾页 30 天行为数据深度诊断与薄弱日识别，今日页支持 AI 一键润色每日成长总结；
- **全家桶生态活动流时间轴**：今日页集成活动流大盘时间轴，支持睡前一键编纂全生态生活轨迹入日记；
- **多端响应与主题自适应**：修复活动流操作按钮在窄屏与手机端的折行换行（flex-wrap），全面使用独立双主题设计令牌消除深色模式刺眼白边。
