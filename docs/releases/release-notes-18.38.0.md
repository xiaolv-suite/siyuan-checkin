## 核心更新

### 1. 移动交互与手势：长按触觉震动与直达精确补卡录入（T-1942）
- **长按轻柔触觉震动反馈**：在手机或触屏端长按打卡卡片触发上下文菜单时，安全调用 `navigator.vibrate(20)` 产生细腻的触觉微触感；
- **菜单直达精确记录与补卡**：卡片右键/长按菜单首位新增“✍️ 精确记录与补记”选项，点击直接就地平滑展开当前卡片的精确数值、备注与精力自评面板并自动聚焦输入框，触控补卡极速闭环。

### 2. 生态建议全景调研与架构决策落地
- **坚守本地优先隐私红线**：正式技术论证并放弃“后台全局监听击键/编辑时长自动打卡”建议，不侵入主线程编辑、不进行任何键盘偷窥，保持可信专注打卡；
- **坚守低压力与反焦虑哲学**：正式技术论证并放弃“游戏化能量珠/金币兑换商店”建议，拒绝外在代币通胀，守护内在习惯自驱力；
- **动态嵌入块与阅读事实自动同步**：确认既有 ````checkin```` 代码块与微信读书三链路自动增量同步方案完全满足期望并持续稳健运行。
