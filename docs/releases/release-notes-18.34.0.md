# 小驴打卡 v18.34.0

「模板组合包冲突预览闭环、开发规范对账与集市平滑同步」小版本发布：深度对账并闭环了组合包部分应用与已有项目冲突预览机制（T-1632），支持在任意库中勾选包内项目、直观查看同名不同规则差异（`lc-checkin__pack-diff`）与一键跳转编辑，并在锁内按最新 Store 重建计划实现原子提交与整批回滚；系统对账并核销了工具链兼容真值（T-1639）、任务型教程与可发现帮助（T-1642）以及社区反馈贡献支持（T-1644）等核心台账；版本号升级至 18.34.0，满足思源官方集市无缝索引要求。主存储保持向前兼容，最低思源版本仍为 3.8.4。

## 核心更新

### 1. 模板与新建：组合包部分应用与已有项目冲突预览闭环（T-1632）
- **按需勾选与部分应用**：支持在空库或已有项目中自如勾选场景组合包内的特定打卡项目，无需整包强推；
- **规则冲突实时对比**：精确比对已有同名项目的排期、目标、单位、时段与方向差异，直观回显变动字段，提供“编辑已有项目”快捷入口；
- **锁内原子提交与零污染回滚**：在 `enqueueMutation` 互斥锁内按最新实体快照重校验，仅创建勾选且仍为新增的项目，保存异常整批回滚，取消操作 0 写入。

### 2. 规范与文档体系：核心研发台账对账核销（T-1639, T-1642, T-1644）
- **工具链兼容真值核准（T-1639）**：确认 Node.js (>=20.19.0) 与 pnpm (12.5.1) 探针与引擎要求全绿；
- **教程与全景索引打通（T-1642）**：任务型用户指南、FAQ 与文档全景索引直达入口全部闭环；
- **社区支持与贡献指引（T-1644）**：社区 Issue 模板、安全报告与单主干贡献准则完全统一。
