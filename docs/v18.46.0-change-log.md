# 小驴打卡 v18.46.0 更新日志

发布日期：2026-11-01

### 重点特性

1. **【事项 2.0 / 2.1】生态重塑与紧凑打卡化设计**
   - 学习今日打卡卡片紧凑质感，单卡高度从 312px 压缩到 126px，正面呈现可点击标题 + 倒数胶囊 + 核心日期元数据，次要详情按需折叠；
   - 修复点击事项编辑时右侧表单未回填该事项内容的根因，消除表单草稿竞争；
   - 彻底修复事项列表无法继续下滑的滚动阻断，移除历史残留的固定高度与 `overflow: hidden`，整页顺滑自然滚动；
   - 建立 7 大语义分类体系（生日/纪念日/定期支出/会员续费/健康车辆/节日/计划事项），顶栏提供一键分类芯片筛选；
   - 零配置维护思源文档《📅 小驴事项簿》，向下穿透维护真实原生复选框块（`type='i' AND subtype='t'`）并写入 Task Horizon v3.3.6 标准块属性；
   - 顶栏直通 Task Horizon 日历排程与看板视图，双向勾销对账回流；
   - 落地小驴人脉（siyuan-contacts）双向闭环：支持一键从人脉同步带生日的联系人、卡片直通人脉档案、生日勾销自动回流交往互动足迹；
   - 落地小驴管家（siyuan-home）资产维保联动：支出/续费/健康事项卡片直达管家到期提醒，勾销广播标准生态信封；
   - 适配小驴雷切（siyuan-speed-switch）Bento 3.0 近期事项小组件，扩充富语义分类字段；
   - 为小驴快门（siyuan-quickgate）暴露公开解析与闪电创建接口。

2. **工程质量与测试加固**
   - 新增 `tests/ecosystem-occasions-deep-linkage.test.cjs` 验证生态 API 与双向回流；
   - 新增 `tests/e2e/occasions-v2.spec.mjs` 针对事项全高顺畅滚动、7大分类过滤、人脉生日双向闭环与生态 API 的真实内核 E2E 测试；
   - 修复 E2E 多测试用例并发下临时笔记本缓存竞争，直接向思源内核查询活跃笔记本；
   - CSS 640 KiB 预算绝对守门，`dist/index.css` 锁定在 655,266 字节（余量 94 字节）。
