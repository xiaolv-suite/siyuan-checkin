# 提醒系统交互可用性、卡片密度与通知频控治理报告（T-1611, T-1612, T-1618，D-660）

## 1. 概述与用户主诉闭环

本报告总结并固化提醒体系的三大关键可用性改进：
1. **今日提醒入口布局与回顾跳转优化（T-1611）**：旧设计中“查看全部提醒”作为独立空行撑满首屏垂直空间，新设计将其收拢至主项操作组（`.lc-checkin__priority-reminder-tools`）内，消除空行占位并保留前向箭头图标与平滑跳转；
2. **回顾提醒中心卡片密度与动作布局（T-1612）**：彻底解决右侧动作垂直堆叠造成的卡片过高与纵向空白浪费，在宽容器下将内容、日期与动作收束为自适应横向行，窄容器下保持 44px 无障碍触控安全；
3. **每日提醒频率与关闭机制（T-1618）**：建立跨重载持久的提醒发射凭据与“今日不再提醒”（Mute Today）机制，次日自动自愈解除；提供 `aria-live="polite"` 读屏防抖。

---

## 2. 三大核心治理实践

### 2.1 T-1611：今日入口空间紧凑化
- `src/render/fragments.ts`：将 `data-reminder-center-link` 收拢入 `<span>` 工具组，与当前主打卡项按钮同一行排列；
- 点击后保留发起 RootContext，直接跳转至回顾页提醒中心并聚焦标题；
- 杜绝因无提醒或少提醒而出现的幽灵空行。

### 2.2 T-1612：提醒中心卡片密度与响应式布局
- 桌面宽屏下，`.lc-checkin__reminder-row` 采用 Grid 单行横向对齐（`grid-template-columns: auto minmax(0, 1fr) 96px 118px`）；
- 侧边栏 Dock 与 320px 窄宽下，自适应折行但严格保证按钮高度 ≥ 34px / 触控区 ≥ 44px；
- 状态样式收敛：已完成、延期、跳过统一收纳至行级语义，不产生冗余高度。

### 2.3 T-1618：通知频控与免打扰闭环
- **双重退出通道**：
  - “关闭”（`data-daily-reminder-close`）：临时关闭当前通知卡片，恢复触发前的键盘焦点；
  - “今日不再提醒”（`data-daily-reminder-mute`）：写入持久化免打扰标记，抑制当日后续全部定时提醒，次日零点自动过期恢复；
- **防重复发射凭据**：基于本地民历日与槽位生成确定性凭据，宿主重启或多窗口交错不会重复弹窗；
- **无障碍保障**：使用 `role="status"` 与 `aria-atomic="true"`，重绘时不重复宣告相同文本。
