# 小驴打卡下一阶段方向（2026-10-31 定）

> 本文件是方向层面的单一来源：后续每轮开发先读这里，再读 [`BACKLOG-SINGLE-SOURCE.md`](BACKLOG-SINGLE-SOURCE.md)。

## 一、核心判断

功能已经够用，方向（思源内本地优先的习惯打卡 + 日期事项）也清楚。当前的核心矛盾是**改动成本高过改动价值**，并且今日页这条主路径被重复信息稀释。

判断依据（2026-10-31 实测）：

- 418 个测试里有 265 个直接读源码文本断言，其中 84 个文件共约 581 处断言针对 SCSS/CSS 文本（含“规则必须位于某个注释分区下”这类纯位置断言）；改一行样式经常要同步改两三个正则。
- 生产 CSS 原本 736,092 字节，占 720KiB 硬上限的 99.8%，该上限此前已上调三次（D-242 / D-507 / D-690）。
- `src/features/` 中 25 个纯评估模块运行时零引用，只被各自的测试消费。
- 今日页上，今天排期且未完成的打卡项，会同时出现在「下一步」卡、「优先提醒」横幅和待完成列表里。

## 二、方向选择

停止加功能和逐条打磨，下一阶段只做两件事：降低改动成本，再把主路径做干净。

### 三件事（按执行顺序，已于本轮落地）

1. **测试改为守行为，未接入模块移出 `src`**：
   - 将 25 个运行时零引用的评估模块及 26 个对应测试移至 [`archive/offline-contract-models/`](../archive/offline-contract-models/README.md)（不删除）；保留唯一承载 `model.ts` 外部墓碑保活行为测试的 `tombstone-lifecycle.ts`。
   - 新增 [`tests/helpers/css-cascade.cjs`](../tests/helpers/css-cascade.cjs)，将 17 个因样式合并/死声明清理而断裂的 SCSS 文本正则测试改为对编译后有效层叠结果的断言（`assertEffectiveStyle`），并删除纯注释分区位置断言。
2. **样式覆盖层收敛，下调且锁死 CSS 上限**：
   - 清理被同上下文/同选择器后续规则完全覆盖的死声明、同值重复声明与无竞争冗余 `!important`，合并同父块同选择器与同声明体规则。
   - 修复 `UI-01`（深色模式专注计时器选中预设按钮对比度从 `1.25:1` 提升至实测 `8.95:1`）。
   - `dist/index.css` 从 **736,092 字节**降至 **654,623 字节**（净减 **81,469 字节 / 79.6 KiB**），重复规则字节从 `~9,800B` 降至 `~169B`，`!important` 从 `307` 降至 `259`。
   - 将 `tests/css-hygiene.test.cjs` 的硬上限从 `720 KiB`（737,280 字节）下调至 **`640 KiB`（655,360 字节）**，重复规则上限从 `10,000B` 下调至 `1,000B`，此后只降不升。
3. **今日首屏只保留一个“下一步”**：
   - 去掉「下一步」卡内重复的第三行副标题（`下一步：晨跑锻炼`）。
   - 当优先提醒全为今日待完成习惯（无逾期/当日独立事项）时，将提醒中心入口（`查看全部提醒`）并入「下一步」卡，不再在「下一步」卡下方重复渲染第二张同名习惯提醒横幅。
   - 非今日页（回顾、事项、新建、设置、更多、洞察、归档）隐藏内联每日提醒条（`.lc-checkin:not(.lc-checkin--today) > .lc-checkin__daily-reminder-notice--inline { display: none; }`）。
   - Chromium 实测：340×720 侧栏下首张打卡卡片顶部 `494px`、底部 `574px`（无需滚动即完整可见）；30 项压测下 320px 首卡位置从 `540px` 降至 `482px`，640px 从 `467px` 降至 `418px`。

### 顺手修复

- **FN-01（手动同步今日打卡到日记）**：`syncTodayCheckinsToLifelogJournal` 查重 SQL 支持按 500 行分页（最多 5,000 块），且仅在 `appendBlock` 实际成功时累加 `synced`，全部失败时提示保存失败，不再误报成功或超 500 块重复追加。
- **FN-06 死分支清理**：移除 `src/render/focus-timer.ts` 中 `if (false as boolean)` 死分支。

## 三、不做 / 推迟

- **推迟（非高频路径且无真实用户反馈）**：UI-03（头像裁剪弹窗细节）、UI-04（回顾/诊断弹窗标题跳级）、UI-05（装饰性 Emoji `aria-hidden`）、UI-07（表单失焦即时校验）、UI-08（单项目热力图数据表）。
- **不做（投入产出比低或偏离定位）**：FN-04（自然语言起草第 2 候选）、FN-05（已有项目自然语言规则微调）、FN-06（专注闲置自动暂停，防看纸质书误触发）、BP-010（愿望积分兑换，与低压力定位冲突）。
- **冻结（等外部上游先动）**：Task Horizon / 思阅 / 思播相关联调项（`PL-01`~`PL-03`）。
- **工程与发版纪律收敛**：不再单独立项拆分 `src/index.ts`（改到哪顺手拆到哪）；停止“每 3~5 项小改动升一个版本号 + 每项编号写发布说明和台账”的流程，改为一个阶段完成才出一个版本、只写一份更新日志；不再做新的全量排查轮次。
