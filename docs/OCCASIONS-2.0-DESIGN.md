## 二、 四大模块技术落地设计

### 1. `T-2020`：数据模型平滑扩展与一句话闪电解析（`src/occasions.ts`）
- **无损向后兼容字段扩展**（仅在有值时落盘，旧对象归一化输出字节级不变）：
  - `time?: string`：可选精确时刻 `HH:mm`（`00:00`~`23:59`）；
  - `priority?: "high" | "medium" | "low"`：可选重要性等级；
  - `blockId?: string`：镜像在《📅 小驴事项簿》中的思源原生任务块 ID（`type='i', subtype='t'`）；
  - `contextBlockId?: string`：绑定的思源准备笔记/参考正文块 ID。
- **纯函数 `parseQuickOccasionInput(raw, baseDate)`**：
  - 支持识别相对日期（`今天/明天/后天/N天后/本周X/下周X`）、显式日期（`YYYY-MM-DD` / `M月D日`）、周期词（`每年/农历/每月X号/每周X/每季度/每半年`）、时刻（`15:00` / `下午3点半`）、优先级（`!高/!中/!低/#重要`）、提前天数（`提前N天`）与思源块引用 `((blockId '标题'))`。

### 2. `T-2021`：思源原生任务块双向映射引擎（`src/features/occasion-siyuan-sync.ts`）
- **零配置《📅 小驴事项簿》**：自动在首选笔记本定位（通过 `custom-lv-occasion-book="1"` 属性或路径）或创建《📅 小驴事项簿》。
- **精确对齐 Task Horizon `kernel.js` 任务块协议**：
  - 追加 `- [ ] 🎂 名称` 后自动向下解析真实的任务列表项子块 ID（`type='i' AND subtype='t'`），而非外层列表容器 `type='l'`；
  - 写入标准块属性：
    - `custom-completion-time` & `custom-start-date`：小驴引擎权威计算的下次公历发生日 `YYYY-MM-DD`；
    - `custom-time`：`item.time`（若有）；
    - `custom-priority`：`item.priority`（若有）；
    - `custom-status`：本期完成为 `"done"`，启用待办为 `"todo"`，停用为 `"cancelled"`；
    - `custom-milestone-event`：生日/纪念日自动标记 `"1"`；
    - `custom-remark`：周期摘要 + 里程碑/跨度说明 + 备注；
    - `custom-lv-occasion-id`：小驴事项唯一 ID（用于幂等更新、跨端对账与删除清理）。

### 3. `T-2022`：`window.TaskHorizon` 公共接口双向互通
- **今日待办同屏速览**：安全调用 `window.TaskHorizon.queryTasks({ date: "today", scope: "all", limit: 8 })`，按 `blockId` 自动剔除已存在于小驴事项中的镜像块（防双份重复显示），在【今日】页事项条内直接展示、勾选（`setTaskStatus(id, "done")`）、跳回原文或开启专注计时。
- **重型视图一键交棒**：提供「📅 日历排程」「📋 看板视图」快捷入口，调用 `window.TaskHorizon.openView("calendar" | "kanban")`；未装 Task Horizon 时优雅降级为打开《📅 小驴事项簿》文档。
- **跨端完成回流**：监听 `tm:task-completed` / `task-horizon:task-completed` 并在打开表面时对账思源块复选框状态 `[x]`，自动标记对应事项本期已完成；周期事项跨日进入下一轮后自动推进块日期并复位 `[ ]`。

### 4. `T-2023` & `T-2024`：思源笔记深度结合与轻盈界面重塑
- **准备笔记直达与引文预览**：绑定 `contextBlockId` 的事项展示 `📎 笔记` 跳转与 `💬 引文预览` 浮层；支持从思源文档直接拖拽块进入【事项】页起草。
- **完成即入今日日记 LifeLog**：事项标记完成时自动向当日 Daily Note 追加 `HH:mm 🎯 事项完成：名称`（含块引用与里程碑注记），撤销完成时安全撤回该日记块。
- **640KiB CSS 硬预算守门**：先压缩归并冗余样式规则腾出预算空间，确保新增闪电录入栏、节律徽章与今日待办合流样式后 `dist/index.css <= 655,360 B` 且死类数为 0。
