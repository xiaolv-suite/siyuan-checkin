# 小驴打卡 · 同类产品深度调研与 P0 核心功能落地技术规约

> **适用仓库**：`小驴打卡/` (`siyuan-checkin`)  
> **对标产品**：Streaks (苹果设计大奖)、Habitica (RPG游戏化)、Loop Habit Tracker (科学强度衰减)、Atomic Habits (原子习惯堆叠模型)  
> **核心哲学**：破除“断卡挫败感”，构建“微习惯堆叠仪式流”，打通“打卡即写反思”的思源原生笔记闭环。

## 二、 P0 级别建议加入的核心功能技术方案

### 功能 1：原子习惯链与仪式流（Habit Stacking & Routine Flow）
- **功能逻辑**：允许将多个习惯组合为一个“仪式流”（例如【晨间唤醒仪式】：`温开水 300ml ➔ 冥想 5分钟 ➔ 核心单词 10个`）。
- **交互与 UI**：
  - 桌面与移动端在首页提供【仪式流】卡片，点击“启动仪式”进入沉浸全屏模式；
  - 完成第一项后自动脉冲高亮下一项，带有细腻音效与触控微震动，支持“一气呵成连击打卡”。
- **数据结构**：
  ```typescript
  export interface RoutineFlow {
      id: string;
      name: string; // 如 "晨间仪式"
      icon: string;
      habitIds: string[]; // 顺序执行的习惯 ID 列表
      targetTime: "morning" | "afternoon" | "evening";
      autoNext: boolean;
  }
  ```

### 功能 2：习惯韧性指数与自律免死金牌（Streak Freeze & Habit Resilience Index）
- **功能逻辑**：
  - 终结传统残酷的“只要漏打一天，90 天连击瞬间清零”机制；
  - **免死金牌（Streak Freeze）**：每月自动赠送 2 张或由用户设置，生病或特殊情况漏打时自动消耗免死金牌保住连击；
  - **习惯韧性指数（0-100%）**：采用指数加权移动平均（EWMA），即便断打 1 天，强度仅从 95% 微跌至 91%，连续补打 2 天即可重回巅峰，呵护长期自律心流。
- **算法模型**：
  ```typescript
  export function calculateHabitStrength(history: boolean[], halfLifeDays = 7): number;
  ```

### 功能 3：打卡伴生微反思与思源 Daily Note 原生回写（Micro-reflection to Daily Note）
- **功能逻辑**：
  - 打卡成功后，允许在成功弹框中快捷敲入 1~2 句感悟（如跑步打卡后：“今天心率平稳，配速 5'30''”）；
  - 插件通过 `/api/block/appendBlock` 将打卡时间、习惯名、数值及微反思**自动写入思源当日日记的“今日打卡与行动”子标题下**；
  - 真正实现“打卡行为”与“思源日记知识资产”的原生一体化。

## 三、 双端 UI 与全生态质量红线
1. 移动端 390×844：仪式流提供拇指单手轻触推进，触控靶心 ≥ 44px；
2. 零正文污染：配置与习惯规则保存在 `settings.json`，向日记写入的内容为用户明确授权的新建块，绝不篡改历史块。
