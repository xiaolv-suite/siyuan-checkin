# v18.43.0 变更记录 (2026-10-28)

## 核心台账核销

### T-1684 外部来源迟到响应配置代际守门与写前动态复核（D-607）
- **六大外部生态代际守门全覆盖**：为微信读书、叶归 LifeLog、健康收件箱、笔记推导、思播、思阅六大外部来源建立全面的请求与会话代际守门；
- **写前动态复核**：在 `enqueueMutation` 锁内写事实前，动态复核来源启用状态（`enabled`）、目标项目绑定（`itemId`, `finishItemId`, `notesItemId`, `metricBindings`）、笔记本/文档有效性以及配置指纹（`fingerprint`），并在叶归中动态复核分类映射解析，迟到响应可诊断丢弃，坚决不写旧目标；
- **重载与卸载阻断**：在偏好变更、偏好重载（`applyViewPreferences`）和插件卸载（`onunload`）时统一自增所有外部来源代际，立即使全部在飞请求失效；
- **专项守门测试**：落地 `tests/external-late-response.test.cjs` 守门测试并纳入 `test:v18` 门禁。

### T-1670 API v5 超时、取消、错误码与敏感字段边界强化
- **批量写取消支持**：在 `recordEventsBatch` 引入 `options?: {signal?: AbortSignal}` 取消支持，并在入队前与未执行时提前退出，拒绝并抛出 `Error("checkin: batch recording was aborted")`；
- **宿主未就绪快速失败**：在 `src/api.ts` 的 `recordEventsBatch` 中，统一在宿主未就绪、卸载中或已释放时快速失败（返回 Promise.reject），杜绝进入队列挂起；
- **契约测试同步**：补齐 `tests/api-v5.test.cjs` 中的 AbortSignal 取消断言与宿主未就绪快速失败用例。

### T-1799 事件墓碑生命周期治理与级联删除规范化收口
- **级联删除去重收口**：在 `deleteItemsCascade` 中统一调用 `normalizeEventTombstones` 规范化，消除脏墓碑未去重未排序隐患；
- **性能与安全边界**：固化 50k 事件与 25k 墓碑级规范化与检索性能；对齐《T-1799 墓碑生命周期设计》安全边界。

### T-1662 提醒排期计划预览、恢复今日提醒与 DST/跨午夜安静时段矩阵（D-608）
- **计划预览状态矩阵**：在 `features/reminder-delivery.ts` 落地 `unmuteReminderDeliveryToday` 与 `buildReminderPlanPreview`，全面覆盖 `delivered`、`quiet`、`muted`、`due`、`upcoming`、`disabled` 六大槽位状态；
- **恢复今日提醒自愈**：设置页直观呈现今日静音提示与计划预览，并提供“恢复今日提醒”（`unmuteDailyReminderTodayFor`）操作；
- **环境韧性与幂等性**：严格验证 22:00~07:00 跨午夜安静时段、夏令时/冬令时（DST）本地挂钟时间与修改槽位多窗口强幂等；
- **专项守门测试**：落地 `tests/reminder-schedule-preview.test.cjs` 守门测试并纳入 `test:v18` 门禁。
