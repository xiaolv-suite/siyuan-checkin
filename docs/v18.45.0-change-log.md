# 小驴打卡 v18.45.0 更新日志

发布日期：2026-10-31（本地版本定版，严格未推送远端）

## 新增 (Added)
- **洞察页单项目记录 CSV 导出（BP-005）**：在单项目洞察页新增「导出记录 CSV」入口，支持将当前项目在所选时间范围内的记录按安全公式转义导出为标准 CSV；
- **日期事项 ICS 日历导出（BP-005）**：在事项页头部新增「导出 ICS 日历」按钮，支持将所有已启用事项一键导出为符合 RFC 5545 的 `.ics` 文件（农历年度事项自动展开近三年对应公历日）；
- **习惯韧性指数条与薄弱星期观察上屏（BP-003）**：在洞察页与回顾「习惯强度」面板接通 EMA 习惯韧性进度条及薄弱星期节奏观察；
- **自然语言起草历史落盘与事项意图消歧（BP-004）**：新建页起草结果持久化至 `ai-draft-history.json`（20 条上限、7 天自动过期、跨窗口墓碑防复活），支持最近草案一键填入/删除，并在识别生日、纪念日或单点日期时提供「转为日期事项」直达新建。

## 优化 (Changed)
- **今日行动台首屏紧凑度优化（BP-005）**：收紧今日概览、下一步英雄卡与提醒横幅纵向间距，桌面标准视口无须滚动即可直接看到待打卡列表首项；
- **跨面板控件尺寸统一与样式瘦身（BP-001 / BP-005）**：清除新建页起草面板全部 17 处内联 `style` 硬编码，统一输入框与回顾分析聚焦下拉框高度至标准触控规格；合并重复容器查询与移动端顶栏底栏冗余规则，保持 0 死类且生产 CSS 体积稳居硬预算以下；
- **README 使用体验与历史折叠优化**：首屏精炼说明插件解决的核心问题，更新日志仅展开当前最新版本，将 `18.44.0` 及全部历史版本收起折叠，并基于当前界面重拍预览截图。

## 修复 (Fixed)
- **修复定量热力图空数据崩溃与戒除项达标口径（BP-002）**：修复 `renderQuantitativeHeatmap` 在空 `days` 集合下读取下标越界异常，修正 `atMost` 戒除/上限项目超标日不再计入达标天数；
- **修复回顾分析多维聚焦筛选失真（BP-002）**：按项目聚焦时年度热力图自动切换为 4 阶完成度热力图，按分组聚焦时热力图、分组均衡与 LifeLog 时间轴同步过滤。
