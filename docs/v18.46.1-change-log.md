# 小驴打卡 v18.46.1 更新日志

发布日期：2026-11-12

### 重点更新与修复

1. **思源 3.8.10+ 原生特性适配**
   - 文档内嵌渲染块中的锚点行与习惯行支持右键唤出思源原生文档树上下文菜单（`showDocTreeNativeMenu`），自动缓存并按需解析笔记本归属。

2. **键盘可达与输入法体验加固**
   - 渲染块锚点解析超时/失败后的「点击重试」按钮补齐 Enter/Space 键盘激活（与点击路径完全对等）；
   - 罗盘弹窗键盘导航在拼音/五笔等输入法合成期（IME）整体让路，ArrowUp/Down 候选导航与 Enter 确认选字不再被劫持（ECO-015 契约固化）。

3. **移动端与动效深度打磨**
   - 底部五格导航小字标签补齐截断三件套，窄屏不再溢出挤压；
   - 移动端编辑操作栏适配 iOS `env(safe-area-inset-bottom)` 安全边距；
   - 程序平滑滚动尊重系统 `prefers-reduced-motion` 降级；
   - 桌面端折叠行与能量选项增加 `@media (hover: hover)` 悬停反馈；
   - 视口同步与触摸监听全面改用 passive 监听降负。

4. **全生态契约与可靠性**
   - 固化 `zhCN/enUS` i18n 双字典键集 parity、平滑滚动无障碍降级、以及剪贴板写入失败覆盖率契约测试。
