### 第二层：高风险区深度链路（核心流程、数据写入删除、空态恢复）
- **打卡写入与即时留痕**：
  - 打卡触发 `recordEvent`，本地 store 即时更新，连击数、完成率计算准确，并按防抖调度落盘写入。
  - 写入思源今日日记 LifeLog：每次打卡以毫秒级时间戳生成 `HH:mm 项目：备注` 格式追加至今日日记，并记录思源 blockId 以备撤销。
- **打卡撤销与安全删块**：
  - 点击「撤销打卡」或右键取消，store 移除对应事件并立即调用 `/api/block/deleteBlock` 精准移除日记中对应块，日记无残留。
- **批量模式完整闭环**：
  - 勾选多项进行批量打卡、批量跳过、批量归档、批量删除，支持全部撤销与多项并发写入队列排队保护。
- **首次使用与空态恢复**：
  - 当今日打卡项为空时，呈现引导卡片，提供「快速创建」与「从内置模板挑选」两大路径，无死锁；全部完成时呈现达成徽章与热力图点亮态。

### 第三层：全局横向比对（一致性、兼容性、性能、安全）
- **一致性**：图标一律使用思源原生 SVG 图标（`iconLvCheckin` 等），线宽与尺寸均为 16px/18px，配色随宿主明暗主题同步；卡片间距 12px，阴影与圆角遵循设计规范。
- **兼容性**：在窄屏 340px（移动端与窄侧栏）到 1920px 宽屏下均流体自适应，网格从 1 列平滑自适应至 3 列，卡片无文字重叠截断。
- **性能**：打卡响应时间 < 16ms（首帧乐观更新），后台防抖合并写入，内存无泄露。
- **安全**：所有用户输入（项目名称、备注、跳过原因）拼入 HTML 前一律经 `escapeHtml()` 处理，杜绝 XSS 注入；本地日记写入与删除只限定在插件自写的打卡块范围内，绝不篡改用户既有文档内容。
