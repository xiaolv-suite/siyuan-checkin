# 设置分区与任务入口再梳理先行研究报告（T-1734，D-646）

## 1. 架构目标与重构背景

在经历 T-1564～T-1567 的分区归并后，设置页收拢为四大主分区（外观与操作、今日与提醒、联动与目标、数据与恢复）。然而，随着生态来源（思阅、思播、微信读书、健康收件箱、叶归、笔记推导）与多桶备份治理能力的持续扩展，第三方来源卡片（如微信读书）呈现出长字段堆叠趋势，新用户难以直观理解“先配置什么、后验证什么”。

本研究承接 T-1555 的长文折叠与去重成果，确立“以用户任务为导向”（Task-Oriented / 先做什么）的配置路径梳理模型，避免单纯搬移 DOM 节点的迁组，同时保持 100% 向后兼容既存的搜索词索引、DOM `data-*` 选择器、书签及事件处理器。

---

## 2. “先做什么”五大核心任务流

```
[任务 1: 日常显示与提醒] ──> 外观质感 ──> 今日布局 ──> 提醒与安静时段
[任务 2: 第三方自动记录] ──> 凭据接入 ──> 习惯绑定与阈值 ──> 探测拉取验证
[任务 3: 思源笔记写入]   ──> 模式选择 ──> 笔记本与文档绑定 ──> 模板格式化
[任务 4: 数据恢复与备份] ──> 导出备份 ──> 快照列表与回滚 ──> 诊断与审计
[任务 5: 宿主与生态能力] ──> 专注计时提供方 ──> API v5 / 契约状态
```

### 任务 1：日常显示与提醒 (`daily_display_reminders`)
- **Step 1（基础质感）**：主题（跟随系统/深色/浅色）、界面语言、品牌调色板。
- **Step 2（今日布局）**：项目分组模式、卡片排序权重、已完成项折叠、周历快捷跳选条。
- **Step 3（提醒与安静）**：每日提醒总开关、每日提醒时刻槽（支持峰值小时推荐）、夜间安静免打扰窗口。

### 任务 2：第三方自动记录 (`auto_ingest`，以微信读书为例)
- **Step 1（凭据接入）**：输入私有密钥 `data-weread-key`，系统提供遮罩脱敏与存储隔离，杜绝跨设备导出泄露。
- **Step 2（规则与阈值）**：绑定目标打卡项 `data-weread-item`，设置达标时长 `data-weread-threshold`（默认推荐 15 分钟）。
- **Step 3（探测与验证）**：点击 `data-action="weread-pull"` 立即拉取并核验状态，查验 `data-weread-status` 输出的首条事实，确认闭环。

### 任务 3：思源笔记写入 (`note_output`)
- **Step 1（模式选择）**：确定日记写入模式 `data-journal-mode`（单向追加打卡记录，严禁覆写历史）。
- **Step 2（笔记本与文档绑定）**：显式指定目标笔记本 `data-journal-notebook-id` 与文档 ID `data-journal-target-doc`。
- **Step 3（模板格式化）**：自定义输出模板，点击 `data-action="save-journal-settings"` 进行显式表单保存并持久化。

### 任务 4：数据恢复与备份 (`data_recovery`)
- **Step 1（导出安全备份）**：点击 `data-action="export-envelope"` 生成全量备份包。
- **Step 2（快照审阅与回滚）**：展开 `data-recovery-guide`，在自动捕获的快照链中选择恢复点 `data-action="restore-snapshot"`。
- **Step 3（诊断与审计）**：导出诊断快照 `data-action="export-diagnostics"` 与操作审计日志。

### 任务 5：宿主与生态能力状态 (`capability_status`)
- **Step 1（专注提供方选择）**：根据 Dock Tomato 插件健康状态选择内置专注或外部联动。
- **Step 2（生态契约只读核验）**：核对 API v5 契约提供状态与 Task Horizon 观察级待验状态。

## 3. 字段 / 动作 / 状态兼容性保证

为杜绝任何重构对现有功能、脚本或自动化测试造成的破坏，确立以下向后兼容硬性约束：
1. **DOM 属性不变**：所有 `data-setting-*`、`data-action=*`、`data-contract-*` 属性保持字面一致；
2. **事件处理器不变**：`bindSettings` 的委派选择器无缝匹配任务流步骤中的目标元素；
3. **设置搜索不变**：`settings-search` 针对中文、英文、别名与拼音的关键词索引继续精准定位到对应行与卡片；
4. **跨表面回链不变**：来自 Today、Review、渲染块的 `data-goto-binding` 能够平滑跳转并高亮目标控件。

## 4. 纯逻辑模型与测试契约

- 纯模型：`src/features/settings-task-journey.ts`（无时钟、确定性、依赖倒置）；
- 守门测试：`tests/settings-task-journey.test.cjs`（100% 验证 5 大任务、步骤推进判定与生产代码属性映射）。
