# 小驴打卡 v18.45.1 更新日志

发布日期：2026-11-01（本地发版定版，严格未推送远端）

## 新增 (Added)
- **智能生态联动 Hub 与一键全开启**：设置页新增生态速览 Hub 卡片，动态感知思阅、思播、底栏番茄钟、今日日记 LifeLog、微信读书 5 颗插件状态胶囊，提供「✨ 一键开启全部可用联动」按钮，单次点击全自动完成所有已安装插件的习惯项创建、双向绑定与启用；
- **零配置日记输出与自动回退**：日记报告、常驻摘要、健康指标收件箱及叶归 LifeLog 未配置目标时自动回退写入今日日记，思阅/思播首次事件到达自动创建同名打卡项（显式停用受到严格保护）；
- **LifeLog 时间轴提升为回顾页第 4 个一级页签**：独立平铺呈现全天事件流，支持按项目与分组多维筛选下钻；打卡/跳过默认自动以 LifeLog 格式追加至今日日记并支持撤销清理。

## 优化 (Changed)
- **宽屏与单独弹窗全面流体自适应**：彻底解除主工作区（Tab）与单独弹出窗口（Quick Dialog）内锁死 960px / 700px 的历史硬限制，引入流体响应式阶梯（今日页平滑铺展至 1800px，弹窗铺展至 1780px），卡片自动多列流动排布，消除两侧死白空白（空白边距由 340px 骤降至 27px~41px）；
- **高密度单卡独立分散化**：拆除连续单板包裹，恢复 `gap: 12px` 与独立边框圆角，操作行下沉独占单行，彻底消除卡片拥挤与多档打卡芯片挤压正文竖排；
- **事项页三板块重组与心智收敛**：事项页重构为「新建」「已有事项（常驻搜索、分类与排序）」「其他（ICS导出与指引）」三板块，「转打卡」移入编辑表单高级区，回归事项本质；
- **导航与信息架构梳理**：顶部导航更名为更准确的「新建打卡」，「更多」页重组为快捷操作、项目与数据、偏好与帮助三大功能分组；
- **设置页字体层级规整**：规整分类标题为 14px、行标签为 13px、提示文字为 11.5px，消除字体过大突兀感。

## 修复 (Fixed)
- **修复完成打卡弹出回执小窗时的整页闪烁**：移除 `.lc-checkin` 的全局平滑滚动，全量重绘时即时锁定与恢复滚动位置；
- **修复浅色模式下专注番茄钟白底白字**：专注计时器与预设时长卡片全面迁移至现代化主题感知变量，实测对比度提升至 16.33:1；
- **修复智能体建议工作流语义比较冲突与 Flaky**：在 `suggestionValuesEqual` 中对 `priority`、`tomatoMode`、`timeSlot`、`group` 等可缺省字段与默认值进行语义归一化，彻底消除工作流采纳冲突；
- **修复微信读书分步配置渲染顺序**：将必需的时长项目移至折叠面板首行，可选完读与笔记指标收进高级折叠区，符合严格契约分步指引；
- **修复真实 E2E 走查中的 Toast 悬浮遮挡**：在自动化交互走查中增强思源内核全局 Snackbar 提示条遮挡点击的容错处理；
- **严格预算约束**：生产 CSS 保持 0 死类、0 重复规则，严格控制在 640KiB 硬上限之内。
